# Mini HTML/JS Games

Коллекция из 22 небольшие браузерные игры без сборки и серверной логики. Каждая игра — самостоятельная HTML-страница с CSS и JavaScript, которую можно открыть из общего каталога `index.html`.

## Звуковой модуль

Все игры подключают общий модуль [`game-audio.js`](game-audio.js). Он синтезирует фоновую музыку и эффекты через Web Audio API без внешних аудиофайлов. Панель в правом верхнем углу позволяет отключить звук и плавно настроить громкость; оба параметра сохраняются в `localStorage` и применяются при следующем запуске любой игры.

Игры могут запускать тематические эффекты через небольшой публичный API:

```js
window.gameAudio?.play('bounce');
window.gameAudio?.setVolume(0.7);
window.gameAudio?.mute(true);
```

Доступны семантические эффекты `bounce`, `brick`, `shoot`, `explosion`, `collect`, `score`, `lose`, `success`, `action` и `move`. Например, Arkanoid и Pong озвучивают отскоки и набор очков, а Cannon — выстрел и взрыв. Опциональная цепочка `?.` позволяет игровой логике продолжать работу, даже если браузер не поддерживает Web Audio API.

## Локальный запуск

Страницы используют абсолютные пути, поэтому открывайте проект через HTTP-сервер из корня репозитория, например:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Тесты

Требуются Node.js 18+ и Chromium для Playwright:

```bash
npm install
npx playwright install chromium
npm test
```

Playwright сам запускает локальный статический сервер на `http://127.0.0.1:4173`.
